# Yumma v1.6 — Judge-facing Demonstration Mode

- Added a browser-based judge console with four synthetic scenarios.
- Scenario selection calls the server-side deterministic agent engine.
- Displays expected vs actual posture, risk signals, and explicit authorization/external-action checks.
- Reset endpoint clears the temporary conversation session and restores the demo screen.
- The normal free-text conversation experience remains available.

Limitations: synthetic scenarios and local prototype only; no real bank integration, no independent validation, no production hosting or authentication.
